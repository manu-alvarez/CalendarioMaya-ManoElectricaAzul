# Mano Eléctrica Azul

Repositorio del proyecto de calendario maya. El árbol de rutas de Expo conserva una [pantalla de bienvenida de la plantilla](app/%28tabs%29/index.tsx).

## Desarrollo local

Las instrucciones genéricas de Expo requieren un `package.json` con las dependencias y el punto de entrada. La raíz de esta rama carece de ese manifiesto. Para reproducir la aplicación hace falta identificar el directorio de compilación o recuperar el manifiesto de la versión correspondiente.
